\# Fraud Email Detection System



\## Project Description

The Fraud Email Detection System is a machine learning-based application that helps identify potentially fraudulent emails. Users can enter email text and receive a prediction through a simple web interface.



\## Features

\- Email text input

\- Machine learning-based prediction

\- Simple and user-friendly interface

\- Real-time prediction using Streamlit



\## Technologies Used

\- Python

\- Streamlit

\- Pandas

\- Scikit-learn

\- Machine Learning



\## Project Files

\- `app.py` – Runs the web application.

\- `train\_model.py` – Trains the machine learning model.

\- `email\_model.pkl` – Stores the trained model.

\- `dataset/` – Contains the dataset.

\- `requirements.txt` – Lists the required Python packages.



\## How to Run

1\. Install Python.

2\. Install the dependencies:



&#x20;  `pip install -r requirements.txt`



3\. Train the model if needed:



&#x20;  `python train\_model.py`



4\. Start the application:



&#x20;  `python -m streamlit run app.py`



5\. Open the local URL displayed in the terminal.



\## Disclaimer

This project is an educational prototype. Its predictions may be inaccurate and should not be relied upon as the sole method of detecting fraudulent emails.
